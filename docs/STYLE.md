# Split Fiction — Arabic translation guide

You are translating the full English text of **Split Fiction** (Hazelight, 2025, co-op action-adventure) into Arabic. The current fan translation was literal and wrong; this one must feel like a professional Arabic dub/subtitle: **simple, natural Modern Standard Arabic (فصحى بسيطة وطبيعية), like modern dubbed films**. Not stiff, not word-for-word, not dialect. Above all, it must fit the game's tone and gameplay.

The user approved a sample in this style. The sample's choices (in the glossary below) are binding.

## The story and characters
- **Mio Hudson (ميو)**: sci-fi writer. Guarded, sarcastic, dry humour, blunt, a loner who slowly warms up. Female.
- **Zoe Foster (زوي)**: fantasy writer. Cheerful, chatty, enthusiastic, goofy, optimistic. Female.
- Both are aspiring writers invited by **Rader Publishing (دار رادر للنشر)**. Its CEO **J.D. Rader (رادر)**, a smug, manipulative tech-CEO villain, plugs writers into **The Machine (الآلة)** to steal their ideas. Mio falls into Zoe's simulation, and they become trapped in shared worlds that alternate between Mio's **sci-fi** stories (cyber cities, robots, enforcers, spaceships) and Zoe's **fantasy** stories (dragons, trolls, fairies, ogres, monkeys, kings). There are also **Side Stories (قصص جانبية)**: short bonus worlds, often absurd and comedic (pig farm, game show, dentist, moon market, sketchbook, and so on).
- Mio and Zoe are both women. Use **feminine** forms when they speak to each other or about themselves, and whenever an NPC addresses one of them. When someone addresses both of them, use the feminine dual or a natural plural (تعاليا / هيا بنا). Enemy soldiers talking about "them" or "the intruders" use the dual or plural as fits.
- Other speakers: infer gender and role from the namespace or key names (for example `VillagerMaleD`, `EnforcerBasicA` = male soldier, `Sarge` = sergeant, `Shieldotron` = robot, `MushroomLarge`, `CentipedeDad`, `ExecutiePie`). Unknown or mixed groups use the masculine plural.
- **Key and namespace names are your context.** `..._Mio_010` means Mio says it. `..._Zoe_020` means Zoe says it. `SEQ_*` = a cutscene: lines are in order (`_Line_1`, `_Line_2`, ...) and form one conversation, so read the whole scene first. `VO_STO_*` = story dialogue during gameplay. `VO_DES_*` = design/gameplay barks. `VO_COM_*` = combat barks. `VO_EFT_*` = effort sounds.
- **Sentences split across consecutive entries** (for example `..._Line_1` = "So upon completion, Rader's machine will" and `..._Line_2` = the rest): they appear as consecutive subtitles. Translate each part so it reads naturally on its own screen and the two parts flow together. You may redistribute words between the parts, but each part must be non-empty and correspond in timing.

## Register and tone
- Natural, flowing, spoken MSA. Short and punchy, because these are subtitles. Keep roughly the same length as the English.
- Keep the personality: Mio = curt and sarcastic. Zoe = bubbly and exclamatory. Rader = slick corporate smoothness. Fantasy NPCs = a slightly grand or archaic flavour where it fits ("أيها الفارس الشجاع"). Robots = cold and mechanical.
- **Translate meaning, intent and jokes, not words.** Idioms become an Arabic equivalent. Puns get an Arabic pun or a funny equivalent if possible. Otherwise keep the humour, not the literal words.
- Profanity: mild Arabic equivalents (تبًّا، اللعنة، سحقًا، يا للهول). Not vulgar, not erased.
- Interjections and sounds: write them in Arabic letters (آه!، أوه!، واو!، هممم، ههههه، أخ!، آآآه!، أوف، يس!). Effort grunts like "Hnnnghhh" become "هممممف" or "آغغغ". Fictional gibberish languages (for example "Haanee aahoo") are transliterated into Arabic letters approximately.
- Square brackets in VO lines (for example `[Stop the trolls!]`, `[Aaaaaeh!]`) mark shouts, non-verbal sounds, or speech in a foreign language. **Keep the brackets** and translate or transliterate what is inside.

## UI and controls
- Button or action prompts (a single verb shown next to a button) use the **verbal noun (مصدر)**: Jump = قفز، Aim = تصويب، Dash = اندفاع، Shoot = إطلاق النار، Grab = إمساك، Interact = تفاعل، Throw = رمي، Release = إفلات، Steer = توجيه، Glide = تحليق، Shapeshift = تحوّل، Magnetize = مغنطة، Accelerate = تسارع، Drift = انجراف، Smash = تحطيم، Hack = اختراق، Move = تحرّك، Climb = تسلّق، Swing = تأرجح، Roll = تدحرج، Dodge Roll = تدحرج للمراوغة، Double Jump = قفزة مزدوجة، Air Dash = اندفاع في الهواء، Leap Up = وثبة للأعلى، Grapple = الخطّاف، Activate Jetpack = تشغيل الحقيبة النفاثة، Activate Thruster = تشغيل الدافع، Trick / Super Trick / Extreme Trick = حركة استعراضية / حركة خارقة / حركة جنونية، Cancel = إلغاء، Confirm = تأكيد، Back = رجوع، Continue = متابعة.
- Instruction sentences addressed to the player use the generic masculine imperative: "Hold to climb" = "اضغط مطوّلًا للتسلّق". "Hold" (a button) = اضغط مطوّلًا. "Press" = اضغط. "Mash" = اضغط بسرعة / ضغط متكرر. Stick = العصا. Trigger = الزناد.
- Settings and menus use standard Arabic gaming terms. Checkpoint = نقطة الحفظ. Side Story = قصة جانبية. Chapter Select = اختيار الفصل. Subtitles = الترجمة. Closed Captioning = ترجمة المؤثرات الصوتية. Gameplay Subtitles = الترجمة أثناء اللعب. Master Volume = مستوى الصوت العام. Dialogue Volume = مستوى صوت الحوار. Invert Vertical = عكس المحور العمودي. Camera Shakes = اهتزاز الكاميرا. Reduce Enemy Damage = تقليل ضرر الأعداء. Enabled/Disabled = مفعّل/معطّل. On/Off = تشغيل/إيقاف. Cross-Play = اللعب المشترك بين المنصات. Borderless Windowed = نافذة بلا حواف. Friend's Pass = تصريح الصديق. Lobby = الردهة. Host = المضيف. Invite = دعوة. Sign in = تسجيل الدخول.
- Keep as-is (do not translate): technical labels such as FPS, FSR, DLSS, HDR, FXAA, TAA, 2X/4X, and resolution numbers. Platform and brand names (EA, Steam, PlayStation, Xbox, PSN). Keys in `ShortKeyboardKeys` (short key-cap labels such as LMB, Ctrl, Num 1). Placeholder or dev strings (for example `AttackShip`, `Lorem ipsum…`, `PIN QV`). For `LongKeyboardKeys`, translate common key names (Space Bar = مسافة, Left Shift = Shift الأيسر, Left Mouse Button = زر الفأرة الأيسر).
- **Credits**: translate job titles and department names (Senior Artist = فنان أول، Lead Designer = كبير المصممين، Localization Manager = مدير التعريب/الترجمة، QA Tester = مختبر جودة). Keep **personal names and company or studio names in Latin letters exactly as they are**. Section headers in ALL CAPS become a normal Arabic heading.
- Language names (LANG_*): keep each language's own name (Deutsch, Español, Français…). The `LANG_en` entry is handled separately, so just translate it as "العربية".

## Names glossary (stay consistent)
Mio = ميو، Zoe = زوي، Rader = رادر، Rader Publishing = دار رادر للنشر، The Machine = الآلة، Sarge/Sergeant = الرقيب / أيها الرقيب. Fantasy and sci-fi proper names: transliterate pleasantly (for example Megalith = الميغاليث، Hydra = الهيدرا، Ella = إيلا). Descriptive names (for example "Ice King", "Tree Guardian") are translated (ملك الجليد، حارس الشجرة). Chapter names are short evocative titles. ## HARD formatting rules (a validator checks these)
1. Keep **exactly the same number of `\n` line breaks**. Each line is a subtitle row or a UI row. Keep `\r` too if present, and keep tabs `\t` (credits use "Title\tName").
2. Keep the `CC:` and `NO_CC:` prefixes exactly, in English, at the same line starts. Inside CC text, sound descriptions in parentheses are translated `(تضحك)، (يزفر رادر)، (أزيز الآلة)`. Speaker tags in square brackets are translated: `[Rader]` = `[رادر]`, `[Mio]` = `[ميو]`, `[Zoe]` = `[زوي]`.
3. Keep placeholders such as `{0}`, `{1}`, `{Name}` exactly.
4. Keep a leading "- " (dialogue dash) where the English has one.
5. Use Arabic punctuation (، ؛ ؟) and normal `!` and `...`. Write punctuation in its **natural logical position**: at the END of the sentence, as normal Arabic text. Do **NOT** move "!" or "." to the start of the line. Do **NOT** insert any invisible direction characters (RLM, RLE, and so on). Direction is handled automatically later.
6. Keep leading and trailing spaces if the English has them.
7. Use Western digits (0-9) as in the English.
8. If something must stay unchanged (for example a name or a technical label), output it unchanged.

## Output
Write a JSON object mapping every `id` from the input to the Arabic string: `{"u123": "…", "u124": "…"}`. Include **every id**. Use valid JSON with `\n` escapes. Use the Write tool to save it, then run the validator and fix everything it reports until it prints OK. Warnings about text identical to English are fine only when the text truly must stay unchanged.
